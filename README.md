# iOS-разработка — Лабораторные работы

**Студент:** Краснопольский Сергей Вячеславович  
**Дисциплина:** iOS-разработка

Данный репозиторий содержит лабораторные работы, выполненные в ходе изучения дисциплины «iOS-разработка».

## 📁 Структура репозитория

```
.
├── LICENSE
├── README.md
├── lab1-4/
│   ├── lab1.playground/
│   │
│   ├── lab2.playground/
│   │
│   └── lab3.playground/
│   │
│   └── MyPlayground.playground/
|
└── ...
```

Каждая лабораторная работа хранится в отдельной папке и включает:

- исходный код (плейграунд или проект Xcode)
- краткое описание задания

Примечание: лабораторные работы 1–4 объединены в папку `lab1-4` и представлены в виде playground'ов. Последующие лабораторные работы будут добавляться в корень репозитория как `lab5`, `lab6` и т.д.

## 🛠 Технологии

- **Язык:** Swift
- **Среда разработки:** Xcode
- **Платформа:** iOS (версия указывается в каждой работе)

## 🚀 Как запустить

1. Открыть папку с нужной лабораторной работой
2. Открыть `.xcodeproj` или `.xcworkspace` файл в Xcode
3. Выбрать симулятор или подключённое устройство
4. Нажать `Cmd + R` для запуска
